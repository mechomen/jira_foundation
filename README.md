# JiraFoundation 🚀

JiraFoundation is a modern Agile Project Management and Team Collaboration platform inspired by Jira. It helps teams organize projects, manage tasks, track progress, and collaborate efficiently.

---

## ✨ Features

- 🔐 User Authentication & Authorization
- 📋 Project & Workspace Management
- 📝 Task / Issue Tracking
- 📌 Kanban Board
- 🏃 Sprint Planning
- 👥 Team Collaboration
- 📊 Dashboard & Analytics
- 📅 Deadlines & Priorities
- 🔔 Notifications
- 🌙 Responsive Modern UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Redux Toolkit
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT Authentication
